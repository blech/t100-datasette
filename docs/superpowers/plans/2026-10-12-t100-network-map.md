# T-100 Airport Network Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public page at `/globe/<AIRPORT>` that draws an airport's routes by year (domestic vs international coloured differently) on a globe or flat map, with month drill-down, backed by new Datasette canned queries, plus a repeatable database build script and a locked-down public run mode.

**Architecture:** A Datasette plugin (`plugins/t100_globe.py`) registers the page route; the page is static ES modules in `static/globe/` (served at `/static/globe/` by Datasette's config-directory mode) that fetch same-origin JSON from three new canned queries in `datasette.yml`. Pure logic (URL state, query URLs, route placement, scales) is tested with `node --test`; queries, plugin and build script are tested with pytest against a small fixture SQLite database. Rendering is canvas via vendored d3-geo.

**Tech Stack:** Python 3.14, Datasette 1.0a41 (pinned by `uv.lock`), pytest, SQLite, plain ES modules, d3-geo 3 + topojson-client (vendored), `node --test` (Node 24).

**Spec:** `docs/superpowers/specs/2026-10-12-t100-network-map-design.md`

**Deviations from the spec (amend the spec in Task 12):**
- The flat map uses d3-geo's built-in **Equal Earth** projection, not flightglobe's interrupted Goode homolosine. The homolosine needs two more vendored libraries and a UMD shim, and its renderer is built around flight tracks. Equal Earth is in `d3-geo` itself.
- From flightglobe we reuse `geo.js`, `camera.js`, `interaction.js`, `themes.js` (copied unchanged, with their tests). The renderers, `flatcamera.js` and the playback/timeline code are not reused; `renderer.js` is new and small.
- The container image and platform config are **not** in this plan (hosting platform is undecided per the spec). Task 5 delivers the locked-down run command and tests that the settings work.
- The BTS airport table as a second coordinate source is **not** in this plan (its coverage is unchecked). Task 2 ships a small override table for the biggest unplaced codes; Task 12 documents how to list what is still unplaced.

## Global Constraints

- Datasette version: the one in `uv.lock` (1.0a41). Canned queries live in `datasette.yml` and load with directory mode (`datasette .`) or `-c datasette.yml`; `queries` in a `-m` metadata file are ignored.
- The Datasette database name is `t100` (from `t100.db`); queries are addressed as `/t100/<query>.json`.
- Queries read the `t100` view (`domestic` 0/1 column first) unless they need one side only.
- Row cap: `max_returned_rows: 50000`; `sql_time_limit_ms: 5000` unchanged.
- `service` rule: a route in a year is `domestic` if the domestic rows' share of `departures_performed` is **more than half**; otherwise `international` (ties, and zero departures, are `international`). The rule lives in SQL only.
- Public mode: `default_allow_sql off`, `allow_download off`, `default_cache_ttl 86400`, database opened `--immutable`.
- No CDN: d3-geo, d3-array, topojson-client and land data are vendored under `static/globe/vendor/`.
- The globe page must not depend on `datasette-agent`, `llm` or any package not in this repo's `pyproject.toml`.
- Colours: international `#ff5a00`, domestic `#2a9df4`.
- Page URL state: path `/globe/<IATA>`; query `year`, `month`, `proj` (`globe`|`flat`), `theme`.
- Data (`*.db`, `*.csv` except `data/airport_overrides.csv`) stays out of git (`.gitignore` already ignores `*.db` and `*.csv`; Task 2 adds an exception).

## Review Focus

Each line below has a test in the named task.

1. **Unknown or lower-case origin** (`/globe/zzz`, `origin=atl`) → `routes_by_year` returns no rows (not an error); the page shows "No data" (Task 3, Task 9).
2. **Pair present in both tables** (LAX–SFO style) → one row per destination and year, `service` by majority of departures; an exact tie is `international` (Task 3).
3. **Airport with no coordinates** → the route is dropped, its code listed in `skipped`, and the page footnote counts it; an origin with no coordinates shows a clear message (Task 8, Task 11).
4. **Freight-only route** (passengers 0, departures > 0) and **zero departures** → `service` computed from departures; widths never `NaN` (Task 3, Task 8).
5. **Result truncated at the row cap** → `truncated: true` is surfaced and the page shows a warning rather than silently drawing partial data (Task 3, Task 8).

```python
"""Build helpers for the T-100 database: schema, indexes, view."""
import sqlite3

# (name, SQLite type). Same positions as the BTS pipe-delimited files; the raw
# files have one extra, empty trailing field (see FIELDS_PER_ROW).
SEGMENT_COLUMNS = [
    ("year", "INTEGER"),
    ("month", "INTEGER"),
    ("origin", "TEXT"),
    ("origin_city_market_id", "TEXT"),
    ("origin_wac", "INTEGER"),
    ("origin_city_name", "TEXT"),
    ("dest", "TEXT"),
    ("dest_city_market_id", "TEXT"),
    ("dest_wac", "INTEGER"),
    ("dest_city_name", "TEXT"),
    ("carrier", "TEXT REFERENCES [carriers]([carrier])"),
    ("carrier_entity", "TEXT REFERENCES [carriers]([unique_carrier_entity])"),
    ("carrier_group", "TEXT"),
    ("distance", "INTEGER"),
    ("class", "TEXT"),
    ("aircraft_group", "TEXT"),
    ("aircraft_type", "TEXT REFERENCES [aircraft_types]([ac_typeid])"),
    ("aircraft_config", "TEXT"),
    ("departures_performed", "INTEGER"),
    ("departures_scheduled", "INTEGER"),
    ("payload", "INTEGER"),
    ("seats", "INTEGER"),
    ("passengers", "INTEGER"),
    ("freight", "INTEGER"),
    ("mail", "INTEGER"),
    ("ramp_to_ramp", "INTEGER"),
    ("air_time", "INTEGER"),
    ("wac", "INTEGER"),
]
FIELDS_PER_ROW = len(SEGMENT_COLUMNS) + 1  # trailing '|' adds one empty field
SEGMENT_TABLES = ("t100_international", "t100_domestic")

_INDEXES = [
    ("pk_nonunique", "year, month, origin, dest, carrier_entity, aircraft_type, class"),
    ("origin_date_dest", "origin, year, month, dest"),
    ("origin_dest_year", "origin, dest, year"),
]
_LOOKUP_INDEXES = [
    ("idx_carriers_carrier_entity", "carriers", "carrier_entity"),
    ("idx_aircraft_types_ac_typeid", "aircraft_types", "ac_typeid"),
    ("idx_openflights_airports_iata", "openflights_airports", "iata_code"),
]

_LOOKUP_TABLES = """
CREATE TABLE IF NOT EXISTS "carriers" (
   [airline_id] TEXT, [carrier] TEXT, [carrier_entity] TEXT, [name] TEXT,
   [unique_carrier] TEXT, [unique_carrier_entity] TEXT, [unique_carrier_name] TEXT,
   [wac] TEXT, [carrier_group] TEXT, [carrier_group_new] TEXT, [region] TEXT,
   [start_date_source] TEXT, [thru_date_source] TEXT
);
CREATE TABLE IF NOT EXISTS "aircraft_types" (
   [ac_typeid] TEXT, [ac_group] TEXT, [ssd_name] TEXT, [manufacturer] TEXT,
   [name] TEXT, [short_name] TEXT, [begin_date] TEXT
);
CREATE TABLE IF NOT EXISTS "openflights_airports" (
   "id" INTEGER, "name" TEXT, "city" TEXT, "country" TEXT, "iata_code" TEXT,
   "icao_code" TEXT, "latitude" REAL, "longitude" REAL, "altitude" REAL,
   "timezone" TEXT, "dst" TEXT, "tz" TEXT, "type" TEXT, "source" TEXT
);
CREATE TABLE IF NOT EXISTS "airport_overrides" (
   [code] TEXT PRIMARY KEY, [name] TEXT, [city] TEXT, [country] TEXT,
   [latitude] REAL, [longitude] REAL
);
"""


def _segment_ddl(table):
    cols = ",\n".join(f"   [{n}] {t}" for n, t in SEGMENT_COLUMNS)
    return f'CREATE TABLE IF NOT EXISTS "{table}" (\n{cols}\n)'


def _view_sql():
    cols = ", ".join(n for n, _ in SEGMENT_COLUMNS)
    return (
        f"CREATE VIEW IF NOT EXISTS t100 AS "
        f"SELECT 0 AS domestic, {cols} FROM t100_international "
        f"UNION ALL SELECT 1, {cols} FROM t100_domestic"
    )


def create_schema(conn: sqlite3.Connection) -> None:
    conn.executescript(_LOOKUP_TABLES)
    for table in SEGMENT_TABLES:
        conn.execute(_segment_ddl(table))
    conn.execute(_view_sql())
    conn.commit()


def create_indexes(conn: sqlite3.Connection) -> None:
    for table in SEGMENT_TABLES:
        for suffix, cols in _INDEXES:
            conn.execute(f"CREATE INDEX IF NOT EXISTS idx_{table}_{suffix} ON {table} ({cols})")
    for name, table, col in _LOOKUP_INDEXES:
        conn.execute(f"CREATE INDEX IF NOT EXISTS {name} ON {table} ({col})")
    conn.commit()
```

```python
import asyncio
import sqlite3
from pathlib import Path

import yaml
from datasette.app import Datasette

from build_database import SEGMENT_COLUMNS

ROOT = Path(__file__).resolve().parent.parent
_NAMES = [n for n, _ in SEGMENT_COLUMNS]


def _insert(db_path, table, rows):
    conn = sqlite3.connect(db_path)
    for row in rows:
        cols = list(row)
        conn.execute(
            f"INSERT INTO {table} ({', '.join(cols)}) VALUES ({', '.join('?' for _ in cols)})",
            [row[c] for c in cols],
        )
    conn.commit()
    conn.close()


def add_segments(db_path, table, rows):
    for row in rows:
        unknown = set(row) - set(_NAMES)
        assert not unknown, f"unknown segment columns: {unknown}"
    _insert(db_path, table, rows)


def add_airports(db_path, rows):
    """rows: dicts with iata_code, name, city, country, latitude, longitude."""
    _insert(db_path, "openflights_airports", rows)


def add_overrides(db_path, rows):
    _insert(db_path, "airport_overrides", rows)


def make_datasette(db_path, settings=None):
    config = yaml.safe_load((ROOT / "datasette.yml").read_text())
    return Datasette(
        [str(db_path)],
        config=config,
        plugins_dir=str(ROOT / "plugins"),
        template_dir=str(ROOT / "templates"),
        static_mounts=[("static", str(ROOT / "static"))],
        settings=settings,
    )


async def _get(ds, path):
    await ds.invoke_startup()
    return await ds.client.get(path)


def get(ds, path):
    return asyncio.run(_get(ds, path))


def get_json(ds, path):
    response = get(ds, path)
    assert response.status_code == 200, f"{path} -> {response.status_code}: {response.text[:300]}"
    return response.json()
```

```python
import csv


def load_airport_overrides(conn: sqlite3.Connection, csv_path) -> int:
```

```yaml
      airports:
        sql: |
          SELECT
            code, name, city, country, latitude, longitude,
            CASE WHEN country IN ('United States', 'Puerto Rico', 'Guam', 'Virgin Islands',
                                  'American Samoa', 'Northern Mariana Islands')
                 THEN 1 ELSE 0 END AS is_us
          FROM (
            SELECT iata_code AS code, name, city, country, latitude, longitude
            FROM openflights_airports
            WHERE iata_code IS NOT NULL
              AND iata_code NOT IN ('', '\N')
              AND latitude IS NOT NULL AND longitude IS NOT NULL
              AND iata_code NOT IN (SELECT code FROM airport_overrides)
            UNION ALL
            SELECT code, name, city, country, latitude, longitude FROM airport_overrides
          )
          ORDER BY code
```

```python
def iter_segment_rows(path):
    """Yield one 28-tuple per data row. An optional header line is skipped; fields are
    positional, so header spelling (class vs Svc_Class, Carrier vs carrier) never matters."""
    with open(path, newline="", encoding="utf-8") as f:
        reader = csv.reader(f, delimiter="|", quoting=csv.QUOTE_NONE)
        for lineno, fields in enumerate(reader, start=1):
            if lineno == 1 and fields and fields[0].strip().lower() == "year":
                continue
            if len(fields) != FIELDS_PER_ROW:
                raise ValueError(f"{path}:{lineno}: expected {FIELDS_PER_ROW} fields, got {len(fields)}")
            yield tuple(fields[:-1])


def load_segments(conn, table, paths, batch=50_000):
    if table not in SEGMENT_TABLES:
        raise ValueError(f"unknown segment table {table!r}")
    sql = f"INSERT INTO {table} VALUES ({', '.join('?' for _ in SEGMENT_COLUMNS)})"
    total = 0
    for path in paths:
        chunk = []
        for row in iter_segment_rows(path):
            chunk.append(row)
            if len(chunk) >= batch:
                conn.executemany(sql, chunk)
                total += len(chunk)
                chunk = []
        if chunk:
            conn.executemany(sql, chunk)
            total += len(chunk)
        conn.commit()
    return total


def main(argv=None):
    p = argparse.ArgumentParser(description="Build or upgrade the T-100 database.")
    p.add_argument("--db", required=True)
    p.add_argument("--international", nargs="*", default=[])
    p.add_argument("--domestic", nargs="*", default=[])
    p.add_argument("--overrides", default="data/airport_overrides.csv")
    args = p.parse_args(argv)

    conn = sqlite3.connect(args.db)
    create_schema(conn)
    for table, paths in (("t100_international", args.international), ("t100_domestic", args.domestic)):
        if paths:
            n = load_segments(conn, table, paths)
            print(f"{table}: loaded {n:,} rows", file=sys.stderr)
    create_indexes(conn)
    n = load_airport_overrides(conn, args.overrides)
    print(f"airport_overrides: {n} rows", file=sys.stderr)
    conn.execute("ANALYZE")
    conn.commit()
    conn.close()


if __name__ == "__main__":
    main()
```

```js
const intOrNull = (v) => {
  const n = Number.parseInt(v, 10);
  return Number.isFinite(n) ? n : null;

export function parseState(search) {
  const q = new URLSearchParams(search || '');
  const year = intOrNull(q.get('year'));
  const month = intOrNull(q.get('month'));
  return {
    year: year !== null && year >= 1990 && year <= 2100 ? year : null,
    month: month !== null && month >= 1 && month <= 12 ? month : null,
    proj: q.get('proj') === 'flat' ? 'flat' : 'globe',
  };
}

export function toSearch(state, extra = {}) {
  const q = new URLSearchParams();
  if (state.year !== null) q.set('year', state.year);
  if (state.month !== null) q.set('month', state.month);
  if (state.proj === 'flat') q.set('proj', 'flat');
  for (const [k, v] of Object.entries(extra)) if (v) q.set(k, v);
  const s = q.toString();
  return s ? `?${s}` : '';
}
```

```js
export function indexAirports(rows) {
  const m = new Map();
  for (const r of rows) {
    m.set(r.code, {
      code: r.code, name: r.name, city: r.city, country: r.country,
      lat: r.latitude, lon: r.longitude, isUs: Boolean(r.is_us),
    });
  }
  return m;
}

export function placeRoutes(rows, origin, airports) {
  const from = airports.get(origin);
  if (!from) return { routes: [], skipped: [], originMissing: true };
  const skipped = new Set();
  const routes = [];
  for (const r of rows) {
    const to = airports.get(r.dest);
    if (!to) { skipped.add(r.dest); continue; }
    routes.push({ ...r, from: [from.lon, from.lat], to: [to.lon, to.lat], destCity: to.city, destName: to.name });
  }
  return { routes, skipped: [...skipped].sort(), originMissing: false };
}

export const yearsIn = (rows) => [...new Set(rows.map((r) => r.year))].sort((a, b) => a - b);
export const forYear = (routes, year) => routes.filter((r) => r.year === year);
export const forMonth = (routes, month) => routes.filter((r) => r.month === month);
```

```js
export function widthFor(value, max, lo = 0.6, hi = 4.5) {
  const v = Number(value);
  if (!(v > 0) || !(max > 0)) return lo;
  return lo + (hi - lo) * Math.sqrt(Math.min(1, v / max));
}

  for (const r of routes) {
```

`static/globe/src/renderer.js`:

```js
import { distPointSegment } from './geo.js';
import { colourFor, widthFor } from './scale.js';

const ARC_SAMPLES = 24;

export class NetworkRenderer {
  constructor(canvas, land) {
    const d3 = window.d3;
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
    this.land = land;
    this.theme = null;
    this.w = 1;
    this.h = 1;
    this.mode = 'globe';
    this.projections = {
      globe: d3.geoOrthographic().clipAngle(90).precision(0.3),
      flat: d3.geoEqualEarth().precision(0.3),
    };
    this.baseScale = 100;
    this.R = 100;
    this.path = d3.geoPath(this.projections.globe, this.ctx);
  }

  get proj() { return this.projections[this.mode]; }

  setTheme(theme) { this.theme = theme; }

  setMode(mode) {
    this.mode = mode;
    this.path = window.d3.geoPath(this.proj, this.ctx);
    this.baseScale = this.computeBaseScale();
  }

  resize() {
    const r = this.canvas.getBoundingClientRect();
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    this.w = Math.max(1, r.width);
    this.h = Math.max(1, r.height);
    this.canvas.width = Math.round(this.w * dpr);
    this.canvas.height = Math.round(this.h * dpr);
    this.ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    this.baseScale = this.computeBaseScale();
  }

  computeBaseScale() {
    if (this.mode === 'globe') return Math.min(this.w, this.h * 0.8) * 0.42;
    const probe = window.d3.geoEqualEarth();
    probe.fitExtent([[16, 130], [this.w - 16, this.h - 150]], { type: 'Sphere' });
    return probe.scale();
  }

  // degrees of rotation per pixel of drag
  degPerPx() { return 57.2958 / Math.max(1, this.R); }

  centre() { return [this.w / 2, this.mode === 'globe' ? this.h * 0.46 : this.h * 0.5]; }

  visible(lon, lat) {
    if (this.mode === 'flat') return true;
    return window.d3.geoDistance([lon, lat], this.viewCentre) < Math.PI / 2 - 0.01;
  }

  arcPoints(route) {
    if (!route._arc) {
      const interp = window.d3.geoInterpolate(route.from, route.to);
      route._arc = Array.from({ length: ARC_SAMPLES + 1 }, (_, i) => interp(i / ARC_SAMPLES));
    }
    return route._arc;
  }

  draw(view, routes, opts = {}) {
    const { ctx, theme: t } = this;
    const d3 = window.d3;
    const [cx, cy] = this.centre();
    this.R = this.baseScale * view.zoom;
    this.proj.scale(this.R).translate([cx, cy]);
    if (this.mode === 'globe') {
      this.proj.rotate([view.rot[0], view.rot[1]]);
      this.viewCentre = [-view.rot[0], -view.rot[1]];
    } else {
      this.proj.rotate([view.rot[0], 0]);
      this.viewCentre = [-view.rot[0], 0];
    }

    ctx.fillStyle = t.bg;
    ctx.fillRect(0, 0, this.w, this.h);

    if (this.mode === 'globe' && t.glow) {
      const g = ctx.createRadialGradient(cx, cy, this.R, cx, cy, this.R * 1.12);
      g.addColorStop(0, t.glow);
      g.addColorStop(1, 'rgba(0,0,0,0)');
      ctx.fillStyle = g;
      ctx.beginPath();
      ctx.arc(cx, cy, this.R * 1.12, 0, Math.PI * 2);
      ctx.fill();
    }

    ctx.beginPath();
    this.path({ type: 'Sphere' });
    ctx.fillStyle = t.ocean;
    ctx.fill();

    ctx.beginPath();
    this.path(this.land);
    ctx.fillStyle = t.land;
    ctx.fill();
    ctx.lineWidth = 0.5;
    ctx.strokeStyle = t.coast;
    ctx.stroke();

    if (t.outline) {
      ctx.beginPath();
      this.path({ type: 'Sphere' });
      ctx.lineWidth = 1;
      ctx.strokeStyle = t.outline;
      ctx.stroke();
    }

    const key = opts.widthKey || 'passengers';
    const order = routes.map((r, i) => i).sort((a, b) => Number(routes[b][key]) - Number(routes[a][key]));
    ctx.lineCap = 'round';
    for (const i of order) {
      const r = routes[i];
      ctx.beginPath();
      this.path({ type: 'LineString', coordinates: [r.from, r.to] });
      ctx.strokeStyle = colourFor(r.service);
      ctx.globalAlpha = i === opts.highlight ? 1 : 0.65;
      ctx.lineWidth = widthFor(r[key], opts.max) + (i === opts.highlight ? 1.5 : 0);
      ctx.stroke();
    }
    ctx.globalAlpha = 1;

    ctx.font = '11px -apple-system, system-ui, sans-serif';
    ctx.textBaseline = 'alphabetic';
    for (const r of routes) {
      if (!this.visible(r.to[0], r.to[1])) continue;
      const p = this.proj(r.to);
      if (!p) continue;
      ctx.fillStyle = t.dot;
      ctx.beginPath();
      ctx.arc(p[0], p[1], 1.6, 0, Math.PI * 2);
      ctx.fill();
    }
    const labelled = order.slice(0, opts.labels ?? 8);
    ctx.fillStyle = t.ui.fg;
    for (const i of labelled) {
      const r = routes[i];
      if (!this.visible(r.to[0], r.to[1])) continue;
      const p = this.proj(r.to);
      if (p) ctx.fillText(r.dest, p[0] + 5, p[1] - 5);
    }

    if (opts.origin && this.visible(opts.origin.lon, opts.origin.lat)) {
      const p = this.proj([opts.origin.lon, opts.origin.lat]);
      if (p) {
        ctx.beginPath();
        ctx.arc(p[0], p[1], 5, 0, Math.PI * 2);
        ctx.fillStyle = t.bg;
        ctx.fill();
        ctx.lineWidth = 2.2;
        ctx.strokeStyle = t.ui.fg;
        ctx.stroke();
        ctx.fillStyle = t.ui.fg;
        ctx.font = '600 12px -apple-system, system-ui, sans-serif';
        ctx.fillText(opts.origin.code, p[0] + 8, p[1] - 8);
      }
    }
  }

  hitTest(x, y, routes, maxPx = 6) {
    let best = -1;
    let bestD = maxPx;
    for (let i = 0; i < routes.length; i++) {
      let prev = null;
      for (const pt of this.arcPoints(routes[i])) {
        const s = this.visible(pt[0], pt[1]) ? this.proj(pt) : null;
        if (s && prev && Math.hypot(s[0] - prev[0], s[1] - prev[1]) < this.R * 0.9) {
          const d = distPointSegment([x, y], prev, s);
          if (d < bestD) { bestD = d; best = i; }
        }
        prev = s;
      }
    }
    return best;
  }
}
```

(Note for the flat map: `hitTest` skips segment pairs further apart than `0.9 * R` on screen so arcs crossing the antimeridian don't create a false line across the map.)

```js
function setStatus(text, warn = false) {
  const el = $('status');
  el.textContent = text;
  el.className = warn ? 'warn' : '';
}

function applyTheme(id) {
  themeId = THEMES[id] ? id : 'paper';
  const t = THEMES[themeId];
  const root = document.documentElement.style;
  root.setProperty('--bg', t.bg);
  root.setProperty('--fg', t.ui.fg);
  root.setProperty('--muted', t.ui.muted);
  root.setProperty('--panel', t.ui.panel);
  root.setProperty('--accent', t.ui.accent);
  if (renderer) renderer.setTheme(t);
  try { localStorage.setItem('t100-theme', themeId); } catch (e) { /* storage may be unavailable */ }
  dirty = true;
}

function currentRoutes() {
  if (state.month !== null) return forMonth(monthRoutes, state.month);
  return forYear(yearRoutes, state.year);
}

function pushState() {
  const extra = themeId === 'paper' ? {} : { theme: themeId };
  history.replaceState(null, '', `${location.pathname}${toSearch(state, extra)}`);
}

function updateStats() {
  const routes = currentRoutes();
  const pax = routes.reduce((s, r) => s + Number(r.passengers || 0), 0);
  const deps = routes.reduce((s, r) => s + Number(r.deps || 0), 0);
  const label = state.month !== null ? `${state.year}-${String(state.month).padStart(2, '0')}` : `${state.year}`;
  $('stats').textContent = `${label} · ${routes.length} destinations · ${fmt(deps)} departures · ${fmt(pax)} passengers`;
  $('year-label').textContent = label;
  const notes = [];
  if (skipped.length) notes.push(`${skipped.length} destination${skipped.length === 1 ? '' : 's'} not shown (no coordinates): ${skipped.slice(0, 12).join(', ')}${skipped.length > 12 ? '…' : ''}`);
  $('footnote').textContent = notes.join(' · ');
  if (truncated) setStatus('Too many rows: some routes are missing from this view.', true);
  else if (!routes.length) setStatus('No flights from this airport in this period.');
  else setStatus('');
}

function tooltipText(r) {
  return `${r.dest} · ${r.destCity || ''}\n${fmt(r.passengers)} passengers · ${fmt(r.deps)} departures\n${r.service}`;
}

function showPanel(r) {
  const p = $('panel');
  const q = new URLSearchParams({ origin, dest: r.dest, _hide_sql: '1' });
  const yq = new URLSearchParams({ origin, dest: r.dest, year: String(state.year), _hide_sql: '1' });
  p.innerHTML = '';
  const close = document.createElement('button');
  close.className = 'close';
  close.textContent = '×';
  close.setAttribute('aria-label', 'Close');
  close.onclick = () => { selected = -1; p.hidden = true; dirty = true; };

  p.append(close, h, sub, dl, a1, a2);

}

async function loadMonths() {
  setStatus('Loading months…');
  const res = await fetchRows(queryUrl('routes_by_month', { origin, year: state.year }));

async function showChooser() {
  const res = await fetchRows(queryUrl('top_us_airports', { year: '', sort_column: '' }));
  const box = $('chooser');
  box.append(Object.assign(document.createElement('div'), { textContent: 'Pick an airport:' }));

function bindControls() {
  const proj = $('proj');
  proj.value = state.proj;
  proj.addEventListener('change', () => {
    state.proj = proj.value === 'flat' ? 'flat' : 'globe';
    renderer.setMode(state.proj);

  const tsel = $('theme');
  for (const id of THEME_ORDER) {
    const o = document.createElement('option');
    o.value = id; o.textContent = THEMES[id].label;

  tsel.value = themeId;
  tsel.addEventListener('change', () => { applyTheme(tsel.value); pushState(); });
  $('width').addEventListener('change', () => { dirty = true; });

  const slider = $('year');
  slider.min = '0';
  slider.max = String(years.length - 1);
  slider.value = String(years.indexOf(state.year));
  slider.addEventListener('input', async () => {

  });

  $('play').addEventListener('click', () => {
    if (playTimer) { clearInterval(playTimer); playTimer = null; $('play').textContent = '▶'; return; }
    $('play').textContent = '⏸';
    if (slider.value === slider.max) slider.value = '0';

      state.year = years[Number(slider.value)];

      $('month-toggle').checked = false;
      refresh();

      state.month = null;

function bindCanvas() {
  const hooks = {
    degPerPx: () => renderer.degPerPx(),
    onUserMove: () => { dirty = true; $('tooltip').hidden = true; },
    onReset: () => { Object.assign(view, defaultView()); dirty = true; },
    onHover: (x, y) => {
      const routes = currentRoutes();
      const i = renderer.hitTest(x, y, routes);
      if (i !== hover) { hover = i; dirty = true; }
      const tip = $('tooltip');
      if (i < 0) { tip.hidden = true; return; }
      tip.textContent = tooltipText(routes[i]);
      tip.style.left = `${x + 14}px`;
      tip.style.top = `${y + 14}px`;
      tip.hidden = false;
    },
    onTap: (x, y) => {
      const routes = currentRoutes();
      const i = renderer.hitTest(x, y, routes, 10);
      selected = i;
      if (i >= 0) showPanel(routes[i]); else $('panel').hidden = true;
      dirty = true;
    },
  };
  attachInteraction(canvas, view, hooks);
}

function frame(last, now) {
  const dt = Math.min(0.1, (now - last) / 1000);
  const moving = !view.dragging && (Math.abs(view.vel[0]) > 0.05 || Math.abs(view.vel[1]) > 0.05);
  applyInertia(view, dt);
  if (state.proj === 'flat') view.rot[1] = 0;
  if (moving) dirty = true;
  if (dirty && renderer) {
    dirty = false;
    const routes = state.year === null ? [] : currentRoutes();
    const key = $('width').value;
    const a = airports.get(origin);
    renderer.draw(view, routes, {
      origin: a ? { lon: a.lon, lat: a.lat, code: origin } : null,
      widthKey: key,
      max: maxOf(routes, key),
      highlight: selected >= 0 ? selected : hover,
      labels: 8,
    });
  }
  requestAnimationFrame((n) => frame(now, n));
}

async function loadLand() {
  const res = await fetch('/static/globe/vendor/land-110m.json');
  if (!res.ok) throw new Error(`Could not load land data: ${res.status}`);
  const topo = await res.json();
  return window.topojson.feature(topo, topo.objects.land);
}

async function main() {
  setStatus('Loading…');
  const [land, airportRes] = await Promise.all([loadLand(), fetchRows(queryUrl('airports'))]);
  airports = indexAirports(airportRes.rows);
  renderer = new NetworkRenderer(canvas, land);
  renderer.setMode(state.proj);
  applyTheme(themeId);
  const resize = () => { renderer.resize(); dirty = true; };
  window.addEventListener('resize', resize);
  resize();
  fillPicker();
  bindCanvas();
  requestAnimationFrame((n) => frame(n, n));

  if (!origin) { setStatus(''); await showChooser(); return; }

  const a = airports.get(origin);
  $('title').textContent = a ? `${origin} · ${a.city}` : origin;
  const res = await fetchRows(queryUrl('routes_by_year', { origin }));
  truncated = res.truncated;
  const placed = placeRoutes(res.rows, origin, airports);
  if (placed.originMissing) { setStatus(`No coordinates for ${origin}, so it can't be drawn.`); return; }
  yearRoutes = placed.routes;
  skipped = placed.skipped.slice();
  years = yearsIn(res.rows);
  if (!years.length) { setStatus(`No data for ${origin}.`); return; }
  if (state.year === null || !years.includes(state.year)) state.year = years[years.length - 1];
  if (state.month !== null) await loadMonths();
  if (a) {
    view.rot = [-a.lon, clamp(-a.lat, -70, 70)];
  }
  bindControls();
  refresh();
}

main().catch((err) => { console.error(err); setStatus(`Something went wrong: ${err.message}`, true); });
```
