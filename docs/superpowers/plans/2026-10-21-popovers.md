# Popovers and Chart Conventions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every chart over time shows one HTML popover listing the whole year (or month) in stack order, with colour keys and right-aligned numbers. Heat-map cells use the same box. Row labels and map tooltips share its look. Stacks are ordered like their legends. A route's table follows "Split by".

**Architecture:** A new module, `static/common/popover.js`, holds two pure functions (`periodRows`, `tapAction`) and one DOM function (`attachPopover`), all generalised from the front page's `attachYearTip`.
- Each chart adds an invisible pointer mark, so Plot reports the year or cell under the pointer. It then hands the plot to `attachPopover`, together with a `content(d)` and an `at(d)` function.
- The popover is a `position: fixed` element, so it works inside the heat maps' scrolling boxes.
- One `.popover` CSS class in `static/nav/style.css` styles it and the other tooltips.

**Tech Stack:** Plain ES modules and Observable Plot (`/static/charts/vendor/plot.js`); `node --test`; headless Playwright for browser checks.

**Spec:** `docs/superpowers/specs/2026-10-21-popovers-design.md`

## Global Constraints

- **Numbers:** popover numbers use the shared formatter, `formatCount`/`formatTons` from `static/common/numbers.js`, in the dense form ("51.5 million"). Shares use one decimal place ("62.4%"). Load factor is a percentage to one decimal place.
- **Row order:** rows run from the top of the stack down. Charts pass their stacking `order` bottom-first (Plot's convention), and `periodRows` reverses it. "Other" is drawn on top, so it is the first row.
- **Pointer:** Plot's tips (`tip: true`) are removed from every chart covered here. A chart's `title` channel is removed along with its tip, because a bare `title` would bring back the browser's own SVG tooltips.
- **Touch:** the first tap shows a popover, a second tap on the same year or cell follows its link, and a tap elsewhere hides it. Mouse behaviour is unchanged: hover shows, click follows.
- **Branch:** `popovers`, off `number-precision`. Never push.

## Review Focus

1. **Touch taps:** Plot's own pointer becomes "sticky" on a click, and touch fires `pointerleave` after `pointerup`. A first tap must leave the popover showing and must not follow the link. A second tap on the same bar must follow the link. (Task 2's browser check, using a `has_touch` page and `tap()`.)
2. **Charts with a colour legend:** `Plot.plot` returns a `<figure>` with the legend before the chart's `<svg>`. A ramp legend is itself an `<svg>`, so the chart is the *last* `<svg>`, and positions must be measured from it, not from the figure. (Task 2 helper `chartSvg`; Task 5's heat-map check.)
3. **Popovers inside a scrolling box** (`#heatmap`, `#route-chart-plot`): the popover must sit next to the pointed cell even after the box has been scrolled sideways. That's why it uses fixed positioning from `getBoundingClientRect()`. (Task 5 scrolls the heat map, then hovers.)
4. **The route page's load-factor view** draws lines, not a stack. Its rows must be highest first, and the popover sits at the highest value. (Task 4.)
5. **Stale popovers when a chart redraws** (a menu change rebuilds the plot): the old popover must go with the old plot. That's why it's returned and appended inside the chart's box, which every draw clears. (Task 3: change the measure while a popover is open.)

```js
// The popover every chart over time shares: the whole year (or month) under the pointer, top of the stack first,
// with colour keys and right-aligned numbers; heat-map cells use the same box. The design:
// docs/superpowers/specs/2026-10-21-popovers-design.md

// points -> one record per period, its rows ordered as the chart draws them, top first.
// `order` is the stacking order, bottom first (Plot's); without one, rows are highest first and `top` is the highest
export function periodRows(points, { key, order = null, value = (p) => p.value, format, extra = null, top = null }) {
  const byPeriod = new Map();
  for (const p of points) {
    const k = key(p);
    if (!byPeriod.has(k)) byPeriod.set(k, []);
    byPeriod.get(k).push(p);
  }
  const rank = (p) => (order && order.includes(p.series) ? order.indexOf(p.series) : (order ? order.length : 0));
  return [...byPeriod].map(([period, ps]) => {
    const sorted = order ? [...ps].sort((a, b) => rank(b) - rank(a)) : [...ps].sort((a, b) => value(b) - value(a));
    const total = top ? top(ps) : order ? ps.reduce((s, p) => s + value(p), 0) : Math.max(...ps.map(value));
    return {
      period,
      top: total,
      rows: sorted.map((p) => ({ label: p.series, value: format(value(p)), ...(extra ? { extra: extra(p) } : {}) })),
    };
  });
}

// what a tap on a touch screen does: a new target shows its popover, the one already shown follows its link
export function tapAction(showing, tapped, hasLink) {
  if (tapped === null || tapped === undefined) return 'hide';
  if (tapped !== showing) return 'show';
  return hasLink ? 'follow' : 'show';
}
```

```js
// the chart's own <svg>: a plot with a legend is a <figure>, and a ramp legend is an <svg> too, so take the last
export const chartSvg = (plot) => (plot.tagName.toLowerCase() === 'svg' ? plot : [...plot.querySelectorAll('svg')].at(-1));

const el = (tag, className, textContent = '') => Object.assign(document.createElement(tag), { className, textContent });

// Show `content(plot.value)` beside the point `at(plot.value)` whenever Plot's pointer moves. The chart needs a
// pointer mark (Plot.pointerX for years, Plot.pointer for cells) whose data are the records content() reads.
export function attachPopover(plot, { content, at, keyOf = null, link = () => null }) {
  const pop = el('div', 'popover');
  pop.hidden = true;
  pop.setAttribute('role', 'tooltip');
  const colour = plot.scale('color');
  const key = keyOf || ((label) => (colour ? { kind: 'square', colour: colour.apply(label) } : { kind: 'none' }));
  const idOf = (d) => (d ? String(at(d)) : null);

  function show(d) {
    if (!d) { pop.hidden = true; return; }
    const { title, rows } = content(d);
    const extra = rows.some((r) => r.extra !== undefined);
    pop.className = `popover${extra ? ' with-extra' : ''}`;
    pop.replaceChildren(el('div', 'popover-title', title), ...rows.flatMap((r) => {
      const k = key(r.label);
      const swatch = el('span', k.kind === 'none' ? '' : `key key-${k.kind}`);
      if (k.colour) swatch.style.background = k.colour;
      return [swatch, el('span', '', r.label), el('span', 'num', r.value), ...(extra ? [el('span', 'extra', r.extra ?? '')] : [])];
    }));
    pop.hidden = false;
    const [xv, yv] = at(d);
    const sx = plot.scale('x'), sy = plot.scale('y');
    const box = chartSvg(plot).getBoundingClientRect();
    const x = box.left + sx.apply(xv) + (sx.bandwidth ? sx.bandwidth / 2 : 0);
    const y = box.top + sy.apply(yv) + (sy.bandwidth ? sy.bandwidth / 2 : 0);
    const fitsRight = x + 12 + pop.offsetWidth <= window.innerWidth - 4;
    pop.style.left = `${fitsRight ? x + 12 : Math.max(4, x - 12 - pop.offsetWidth)}px`;
    pop.style.top = `${Math.max(4, Math.min(y - 10, window.innerHeight - pop.offsetHeight - 4))}px`;
  }

  // touch: the first tap shows, a second on the same target follows its link. Plot has moved its pointer by the
  // time pointerdown bubbles up to us, so read the target then; touch also fires pointerleave after every tap.
  let touch = false, tapped = null, showing = null;
  plot.addEventListener('pointerdown', (e) => { touch = e.pointerType === 'touch'; tapped = plot.value; });
  plot.addEventListener('click', (e) => {
    if (!touch) return;
    const action = tapAction(showing, idOf(tapped), Boolean(tapped && link(tapped)));
    if (action === 'follow') { location.href = link(tapped); return; }
    e.preventDefault();
    if (action === 'hide') { showing = null; pop.hidden = true; return; }
    showing = idOf(tapped);
    show(tapped);
  }, true);
  plot.addEventListener('input', () => { if (!touch) show(plot.value); });
  plot.addEventListener('pointerleave', (e) => { if (e.pointerType !== 'touch') pop.hidden = true; });
  document.addEventListener('pointerdown', (e) => {
    if (!plot.isConnected) return;
    if (!plot.contains(e.target)) { showing = null; pop.hidden = true; }
  });
  return [plot, pop];
}
```

```js
// One row per carrier, aircraft, or carrier and aircraft pair (or a single row of totals), following the chart's
// split, summed over the rows given, biggest passenger total first
export function aggregateTable(rows, split = 'both') {
  const byCarrier = split === 'carrier' || split === 'both';
  const byAircraft = split === 'aircraft' || split === 'both';
  const groups = new Map();
  for (const r of rows) {
    const carrier = byCarrier ? name(r.carrier) : null;
    const aircraft = byAircraft ? name(r.aircraft) : null;
    const key = `${carrier}\u0000${aircraft}`;
    const t = groups.get(key) || {
      carrier, aircraft, groupId: byCarrier ? r.group_id || null : null, family: byAircraft ? r.family || null : null,
      deps: 0, seats: 0, passengers: 0, freight: 0,
    };
    t.deps += num(r.deps);
    t.seats += num(r.total_seats);
    t.passengers += num(r.total_passengers);
    t.freight += num(r.total_freight) / LB_PER_SHORT_TON;
    groups.set(key, t);
  }
  return [...groups.values()]
    .map((t) => ({ ...t, loadFactor: t.seats > 0 ? (t.passengers / t.seats) * 100 : null }))
    .sort((a, b) => b.passengers - a.passengers || String(a.carrier).localeCompare(String(b.carrier)) || String(a.aircraft).localeCompare(String(b.aircraft)));
}
```
