# Colour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every data colour comes from one palette module, by role, with light and dark variants. Ember serves the stacked series, teal and ember mark domestic and international, Ember jets fill the engine chart, and ember is the interface accent. Charts redraw when the theme changes.

**Architecture:** `static/common/palette.js` is a pure module holding `PALETTE.light` and `PALETTE.dark`, plus small helpers. Chart pages take colours from it at draw time and redraw on the `t100:theme` event. The map helpers (`scale.js`, `routestyle.js`, `renderer.js`) take the theme's `dark` flag and look colours up in the palette. A guard test stops new hard-coded colours.

**Tech Stack:** Plain ES modules, Observable Plot, canvas maps; `node --test`; headless Playwright.

**Spec:** `docs/superpowers/specs/2026-10-21-colour-design.md`

Create `static/common/palette.js`:

```js
// Every data colour on the site, by role, for the light and dark themes. Ember (deep red to sand) is the family;
// the choices and why: docs/superpowers/specs/2026-10-21-colour-design.md. Heat maps (YlOrRd) and the front page's
// airline liveries are deliberately outside it.

export const PALETTE = {
  light: {
    series: ['#7f1d1d', '#9e261f', '#be301e', '#d44c23', '#e36d2a', '#ef9048', '#f7bb82', '#fae4b8'],
    other: '#a1a1aa',
    service: { domestic: '#0d9488', international: '#e36d2a' },
    kind: { passenger: '#e36d2a', freight: '#64748b' },
    single: '#e36d2a',
    engines: ['#be301e', '#ef9048', '#fae4b8', '#969696', '#d0d0d0'],
    change: { added: '#4dac26', dropped: '#c51b7d' },
    accent: '#e36d2a',
  },
  // lifted: starts brighter and stops short of the palest sand, so nothing sinks into the black or glares
  dark: {
    series: ['#c53a2a', '#d04d2c', '#da5f2d', '#e4712f', '#ec863f', '#f0a05c', '#f3b976', '#f5d290'],
    other: '#a1a1aa',
    service: { domestic: '#2bb39a', international: '#ec863f' },
    kind: { passenger: '#ec863f', freight: '#94a3b8' },
    single: '#ec863f',
    engines: ['#da5f2d', '#f0a05c', '#f5d290', '#8a8a8a', '#5e5e5e'],
    change: { added: '#4dac26', dropped: '#c51b7d' },
    accent: '#ec863f',
  },
};

export const palette = (dark) => (dark ? PALETTE.dark : PALETTE.light);

// a Plot colour scale for stacked series, biggest first: Ember steps in order, "Other" in grey
export function seriesColours(series, dark) {
  const p = palette(dark);
  let i = 0;
  const range = series.map((s) => (s === 'Other' ? p.other : p.series[Math.min(i++, p.series.length - 1)]));
  return { domain: series, range };
}

// the page's theme as the nav script set it, or the system's before it has run
export function isDark() {
  const scheme = globalThis.document?.documentElement?.dataset?.scheme;
  if (scheme) return scheme === 'dark';
  return Boolean(globalThis.matchMedia?.('(prefers-color-scheme: dark)').matches);
}
```
